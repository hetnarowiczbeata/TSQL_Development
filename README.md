# T-SQL Development – AdventureWorks

Project based on the AdventureWorks database.

The goal of this project is to practice and demonstrate:

- SQL queries
- JOINs
- Aggregations
- Views
- Stored Procedures
- CTEs
- Temporary Tables
- Window Functions
- Error Handling
- Sales Analysis

## Database Structure

The project focuses mainly on:

- Sales.SalesOrderHeader
- Sales.SalesOrderDetail
- Production.Product
